# Braaapaganda: Banned without particulars

A public research website about the Braaapaganda YouTube channel termination, the refusal to identify offending content, proportionality of the sanction, and Rumble’s creator protections.

Research cutoff: October 28, 2026. United States; YouTube channel termination only.

## Read the site

- `index.html`: accessible, responsive overview, timeline, statistics and platform comparison.
- `report.html`: detailed analysis, citations, proposed right-of-reply questions and episode outline.

No build process, dependencies, tracking scripts or paid hosting are needed. All links and assets work under a GitHub Pages project path.

## Publish with GitHub Pages

Create a public repository and push these files to its `main` branch. In **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, then **main / (root)** and save. GitHub will display the live URL after deployment.

GitHub Pages is available for public repositories on GitHub Free: [official documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Editorial boundaries

The documented finding is the refusal to provide incident-specific particulars. The actual violation, final automation route and proportionality remain unresolved. The report does not establish that Rumble has a lower wrongful-removal rate or stronger enforceable safeguards.

Private correspondence, original PDFs/screenshots, contact details, account identifiers and affiliate purchasing URLs are not included. Evidence references identify privately retained records and do not imply public access or independent backend authentication.

No right-of-reply inquiry has been sent. The report must be updated to accurately reflect any future outreach and responses. Public terms checked on the research date are not authenticated snapshots of every rule on the removal date.

## Corrections and updates

Support proposed factual corrections with primary sources and distinguish records, platform representations and inference. Do not post personal information or private exhibits in a public issue or pull request.

The site contains no third-party analytics. GitHub’s hosting privacy practices apply when it is deployed on GitHub Pages. Public availability is not a blanket license to reproduce third-party source material.
